# Street Math

**ISO 31010 Risk Assessment Techniques — Through Storytelling**

Ten screenplays that teach formal risk analysis techniques from ISO 31010 through everyday street-level scenarios. No boardrooms. No PowerPoints. Just characters who speak probability, expected value, and root cause analysis in their own language.

## The Screenplays

| # | Technique | ISO Section | Scenario | File |
|---|-----------|-------------|----------|------|
| 1 | Bow Tie Analysis | B.4.2 | A veteran bouncer explains preventative and reactive controls around a bar brawl | `screenplay_bow_tie_analysis.html` |
| 2 | Decision Tree Analysis | B.9.3 | A street hustler maps decision nodes and expected values to decide whether to pay a supplier | `screenplay_decision_tree_analysis.html` |
| 3 | Monte Carlo Simulation | B.5.10 | A mechanic runs 100 mental simulations to show why a quick fix is an 86% failure bet | `screenplay_monte_carlo_simulation.html` |
| 4 | Game Theory | B.9.4 | Two roommates face the Prisoner's Dilemma when their landlord offers a snitch deal | `screenplay_game_theory.html` |
| 5 | Layers of Protection Analysis (LOPA) | B.4.4 | A heist planner calculates probability of failure on demand for each vault protection layer | `screenplay_layers_of_protection_analysis_lopa.html` |
| 6 | Ishikawa (Fishbone) Analysis | B.3.3 | A food truck owner traces a ruined lunch rush through the 6Ms to find root causes | `screenplay_ishikawa_fishbone_analysis.html` |
| 7 | Pareto Charts | B.8.4 | A bartender teaches the 80/20 rule — why 20% of causes drive 80% of revenue loss | `screenplay_pareto_charts.html` |
| 8 | Cross Impact Analysis | B.6.2 | A bookie explains how one injury shifts conditional probabilities across a web of prop bets | `screenplay_cross_impact_analysis.html` |
| 9 | Cost/Benefit Analysis (CBA) | B.9.2 | A loan shark walks a borrower through Net Present Value and a 1,160% effective annual rate | `screenplay_cost_benefit_analysis_cba.html` |
| 10 | Markov Analysis | B.5.9 | A subway busker builds a transition matrix to optimize which train cars to play in | `screenplay_markov_analysis.html` |

## Quick Start

Open `index.html` in any browser. It's the home page with links to all ten screenplays.

Each screenplay is a standalone HTML file — no server, no dependencies, no build step. Just open and read.

## Regenerating

The screenplays are generated by `generate_screenplays.py`. To regenerate:

```bash
pip install Pillow
python3 generate_screenplays.py
```

This reads prompts from `iso_301010_sreenplay_prompts.csv`, generates a unique header image for each screenplay using Pillow, and outputs 10 standalone HTML files.

Requirements:
- Python 3.10+
- Pillow (`pip install Pillow`)

## Design

- Each screenplay has a unique color palette and header image with a visual motif representing the technique (bow tie shape, decision tree, dice, game grid, concentric layers, fishbone, Pareto bars, web graph, balance scale, Markov chain)
- Dark theme, responsive layout, print-friendly CSS
- Header images are base64-encoded directly into the HTML — no external image files needed
- Screenplay text is formatted with character names centered and bold, stage directions italicized, and scene headings accented
