What Is NERIS?

The National Emergency Response Information System is a cloud-based, all-hazards incident reporting platform built by the Fire Safety Research Institute (FSRI / UL Research Institutes) with the U.S. Fire Administration (USFA) and DHS S&T Directorate.

NERIS replaced NFIRS on January 1, 2026. First live incident: January 2025. Nationwide rollout completed across all FEMA regions through 2025.

Governance: Departments own their data. The platform aggregates and anonymizes for national publication — no PII in public feeds.

Key Data Fields Captured

  • Incident type (multi-tag: fire, EMS, hazmat, WUI, etc.)
  • Geospatial coordinates (GIS-native lat/lon)
  • Location type & property use classification
  • Dispatch, en-route, arrival & clear timestamps
  • Suppression tactics & actions taken
  • Civilian & firefighter casualties / rescues
  • Property loss & contents loss (structured)
  • Detector / suppression system performance
  • CAD/dispatch pre-population (automated)

Two Classes of Opportunity for Insurance & Actuarial Professionals

CLASS 1 Cooperative Data Partnerships — Direct access to department-level (non-aggregated) data via data-use agreements with departments, State Fire Marshals, or FSRI/USFA:

  • Hyper-local response time analysis for property underwriting
  • Suppression system effectiveness for commercial risk classification
  • WUI incident density overlaid with policy portfolios
  • ISO/PPC rating validation and improvement support

CLASS 2 Public Aggregated / API Feed — Free, PII-free, near-real-time national data available to verified organizations:

  • Dynamic ISO score modeling using actual incident & response metrics
  • Community Risk Reduction (CRR) data for loss-prevention credits
  • Statewide trend analysis for rate-making & catastrophe modeling
  • Academic research partnerships (SOA, CAS curriculum)

ISO / PPC Link: Fire department reporting completeness and response performance data in NERIS directly factors into ISO Public Protection Classification (PPC) scores — the metric driving homeowner and commercial property premiums. Better data = demonstrable PPC improvement.

Historical Baseline: 45 years of NFIRS data (1980–2025) on OpenFEMA for retrospective analysis.

Proposed Pilot: Project Crucible — Arizona Fire Risk Data Pipeline

Phase 1 — Connect: Establish API integration with NERIS aggregated feed for Arizona incident data. Map NERIS geospatial fields to existing property/policy databases.

Phase 2 — Analyze: Apply ISO 31010 risk methodology to response time, suppression performance, and property-loss fields. Identify underwriting gaps in WUI and high-risk corridors.

Phase 3 — Underwrite: Deliver dynamic risk scoring to captive and standard market carriers — enabling accurate rating of previously uninsurable fire-risk properties.
